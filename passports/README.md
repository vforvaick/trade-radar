# Cryptopass Passports

Strategy configuration files for the Cryptopass automated trading system.

## Structure

- `pumpradar/` — Derivative strategies based on the external Pumpradar alert bot signals
- `cryptopass-research/` — Custom strategies developed and researched by the Cryptopass team

## Loading

The bot loads all `.json` files from all subdirectories at startup. Add new strategies to the appropriate subfolder.
